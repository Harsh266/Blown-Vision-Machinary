Key Observations

  • 100% of data is hardcoded — no CMS, API, database, or backend calls anywhere in the app.
  • Images are either local public/*.png (logo, hero, heroo, solution, about1, about2, contact, texture) or external CDN URLs (machine photos, avatars, board member portraits).
  • Icons come from the lucide-react library — every section uses different icon components.
  • Contact form has no backend — submit shows a browser alert() only.
  • Footer social links are all href="#" placeholders.
  • Some routes referenced in Footer (/solutions, /industry-standards, /global-network, /careers, /sustainability, /privacy-policy, /terms) do not have actual pages defined in the router.
  • Machine detail pages share identical structure but each has unique content for Engineering Excellence, Attachments, Applications, and Specs tables.
  • Rating / trust data ("4.9/5", "Trusted by 10k+") is purely illustrative demo data.
