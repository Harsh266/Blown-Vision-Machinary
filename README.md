# Blown Vision Machinary

Precision-engineered blown film extrusion machinery website built with React, Tailwind CSS, and Vite.

## Tech Stack

- React 19 + Vite 8
- Tailwind CSS 4
- Framer Motion
- React Router DOM
- Lucide React icons

## Getting Started

```bash
cd frontend
npm install
npm run dev
```

## Build

```bash
cd frontend
npm run build
```

## Project Structure

```
frontend/
├── src/
│   ├── components/   # Navbar, Footer, CTA, ScrollToTop
│   ├── pages/        # Home, About, Contact, Machines, NotFound
│   └── pages/machines/ # Monolayer, ABA, ABC machine detail pages
└── public/           # Static images
```
